# Standing brief

## What we are building

A local tool for one job seeker. It reads a job post and your resume, checks every requirement in the post against evidence in the resume, and says exactly which line supports it or marks it not evidenced. It then drafts tailored resume and cover letter text using only the evidenced material. Runs on the user's own machine. No accounts, no hosted data, English only.
